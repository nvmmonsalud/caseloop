# Future roadmap

## Community Growth (Current Focus)

> Building an open-source community around CaseFlow to make it sustainable, contributor-friendly, and eligible for programs like Claude for OSS.

### Phase 1 — Foundation (Month 1–2)

- [x] **Create CONTRIBUTING.md** — comprehensive contributor guide with setup, standards, and PR process
- [ ] **Add issue templates** — bug report, feature request, and case study add templates in `.github/ISSUE_TEMPLATE/`
- [ ] **Add GitHub labels** — `good-first-issue`, `help-wanted`, `case-study`, `AI-pattern`, `analytics`, `UI`, `documentation`
- [ ] **Expand development setup guide** — Codespaces config for zero-friction onboarding
- [ ] **Publish "call for case studies"** — invite MBAs and professors to contribute fictional business cases
- [ ] **Seed 3–5 good first issues** — clearly scoped, documented, and tagged for new contributors

### Phase 2 — Early Momentum (Month 2–4)

- [ ] **Recruit 3–5 initial contributors** from MBA/AI/edtech communities
- [ ] **Submit to communities** — r/MBA, r/edtech, Hacker News, Product Hunt
- [ ] **Add CI/CD badges** — build status, test coverage, TypeScript strictness to README
- [ ] **Create CONTRIBUTORS.md** — acknowledge all contributors with merged PRs
- [ ] **Add GitHub Discussions** — for Q&A, ideas, and community conversation
- [ ] **Write a blog post** — "Building an AI-native case method tool: lessons from CaseFlow"

### Phase 3 — Sustainable Pipeline (Month 4–6)

- [ ] **Target metrics for Claude for OSS** — 20+ stars, 10+ forks, 2+ external contributors with merged PRs
- [ ] **Automate onboarding** — GitHub Codespaces + DevContainer config
- [ ] **Monthly release cadence** — tagged releases with CHANGELOG.md
- [ ] **Apply to Claude for OSS program** — 6 months of free Claude Max for maintainers
- [ ] **Establish maintainer rotation** — share triage and review responsibilities
